Create Music

Easy Mode

Chat with an AI co-producer to create songs — just describe what you want in natural language, and Mureka handles the rest.

Core Capabilities

  1. Conversational creation: describe your idea in a sentence, Mureka generates a full song (lyrics + music)
  2. AI understands context: follow up with refinements like "make it more upbeat" or "change to female vocal"
  3. Quick starters: tap preset prompts like "Make a beat" to get started instantly
  4. Auto-generates song title, lyrics and style descriptions
  5. Supports choosing reference, vocal, and switching to instrumental-only mode

Why Use It

  1. Zero learning curve — no music knowledge needed, just talk to it like a friend
  2. From idea to finished song in seconds to minutes
  3. The fastest way to turn any moment (birthday, heartbreak, a random vibe) into a real song

Boundaries

  1. Each generation produces 2 song variants to choose from
  2. Song length is typically 2–4 minutes
  3. Conversation context is per-session; starting a new chat resets context
  4. Currently supports text input only (no speech input in Easy mode)

Entry

  1. Create tab → Easy

How to Use

  1. Open Easy mode → type "Write a chill lo-fi track for studying" → tap Send
  2. Mureka generates a brief describing your song → automatically creates 2 versions
  3. Listen, pick your favorite, then Publish or Remix/Edit further

Custom Mode

AI-powered lyrics writing tools — generate full song lyrics from a theme, or let AI optimize and rewrite your draft.

Lyrics Generation

AI-powered lyrics writing tools — generate full song lyrics from a theme, or let AI optimize and rewrite your draft.

Core Capabilities

  1. Generate Lyrics: create complete song lyrics from scratch based on a theme or prompt
  2. Optimize: polish and improve existing lyrics while preserving the original meaning
  3. Supports structured output with verse/chorus/bridge tags
  4. Multi-language lyrics generation (English, Chinese, Japanese, Korean, Spanish, etc.)

Why Use It

  1. Overcome writer's block — get a full set of lyrics in seconds
  2. Professional structure — AI follows songwriting conventions (verse-chorus-bridge)
  3. Works as a creative partner — write your draft, then let AI polish it

Boundaries

  1. Generated lyrics are suggestions — you can freely edit them before creating the song
  2. Lyrics quality depends on the clarity of your input prompt, and the writing capability of current technology
  3. Very long or complex narrative lyrics may need manual adjustment

Entry

  1. Create Music → Custom tab → Lyrics input area → "Generate Lyrics" or "Optimize" button

How to Use

  1. Switch to Custom mode → in the Lyrics box, click "Generate Lyrics"
  2. Enter a theme like "missing someone on a rainy night" → AI generates full lyrics with [Verse], [Chorus], [Bridge] structure
  3. Edit any lines you want to change → click "Optimize" to polish the final version
  4. Proceed to set Style, Vocal Gender, and hit Create

Reference track

Upload an audio file as a style reference — Mureka analyzes its sonic characteristics and creates a new original song inspired by it.

Core Capabilities

  1. Upload any audio file (MP3, WAV, etc.) as a reference
  2. AI analyzes the reference's genre, tempo, mood, and instrumentation
  3. Generates a brand-new original song that captures a similar vibe — not a copy
  4. Combines with your lyrics and style inputs for maximum control

Why Use It

  1. "Sound like this but original" — bridge the gap between what you hear in your head and what you can describe in words
  2. Great for producers who work with mood boards and sonic references
  3. Legally safe — generates original compositions, not copies

Boundaries

  1. Reference is for style inspiration only — the output will NOT replicate the original song
  2. Audio files up to 100MB, duration 10s–10min
  3. Works best with clear, well-mixed reference tracks
  4. The AI interprets style loosely. Results may vary from the reference

Entry

  1. Create Music → Custom tab → "+ Reference" button at the top

How to Use

  1. Click "+ Reference" → upload an audio file you like
  2. AI extracts style tags from the reference (e.g., "Indie Pop, Acoustic Guitar, 110 BPM")
  3. Write or generate your own lyrics → hit Create
  4. The generated song will capture a similar feel to your reference but with original composition

Remix

Upload a song and transform it into a completely new style while keeping the melody and lyrics.

Core Capabilities

  1. Upload an existing song (your own or from Mureka library)
  2. AI preserves the core melody and lyrics while re-arranging in a new style
  3. Define the target style (e.g., turn a pop ballad into an EDM banger)
  4. Choose whether to keep original vocals or generate new ones

Why Use It

  1. Breathe new life into existing songs — hear your favorite melody in a totally different genre
  2. Perfect for content creators who need style variations of the same song
  3. Explore unexpected combinations — turn folk into drum & bass, rock into ambient

Boundaries

  1. Audio files up to 100MB; songs longer than 4 minutes may be trimmed
  2. The output is a reinterpretation, not a precise genre transfer
  3. Some extreme genre transformations (e.g., classical → heavy metal) may produce unexpected results

Entry

  1. Create Music → Custom tab → "+ Remix" button at the top; also available from any song's "Remix/Edit" dropdown

How to Use

  1. Click "+ Remix" → upload your song or select one from Library
  2. Define the target style in the Style field (e.g., "Lo-fi hip-hop, chill, vinyl crackle")
  3. Hit Create → Mureka generates a remixed version preserving the original's melody and lyrics
  4. Compare with the original, publish or continue editing

Vocal (Voice Clone)

Upload a voice sample to create a personalized AI vocal — use it to sing any song you create on Mureka.

Core Capabilities

  1. Import a song with clear or a cappella vocals, or record your own singing, as a voice reference to create a fixed singer Character.
  2. Use songs you've created on the platform to extract the voice and generate a fixed singer Character.
  3. Upload an image as the Character's look, used to promote future songs.

Why Use It

  1. Use a fixed singer Character to sing all your songs
  2. The singer Character's look can generate custom music videos
  3. Characters can be discovered and used by others, enabling remix creation and interaction

Boundaries

  1. The Character's voice can be used with a music reference and prompts, but it will mainly follow the Character's own traits.
  2. The Character's voice only serves as a reference for vocal timbre during generation; it does not set vocal range, melody, or genre.
  3. The Character voice currently supports lead melody only; harmony, backing vocals, humming, and other forms aren't supported yet.

Entry

  1. Tap Create, tap the +Vocal button, and select a Character to have it sing your newly generated song.

Create Music Video

Generate a fully AI-rendered music video from a song — configure your character, background, and visual style, then let AI compose every shot or refine each scene yourself before generating.

Core Capabilities

  1. Lip-sync music video: Generate an MV where the character's mouth movements are synchronized to the song's vocals — no manual recording or editing required.
  2. Lyric-aware shot generation: The song's lyrics will be read to generate contextually relevant shots — each scene reflects the mood, narrative, and imagery of the words, not just the music energy.
  3. Storyboard editing before generation: In Storyboard mode, the AI pre-generates a shot-by-shot visual plan. Users can review each frame, regenerate any individual shot they're not happy with, and adjust the storyboard freely — then trigger the final render only when satisfied.
  4. Shareable MV output: The finished MV is saved to the Workspace and ready to download or share. Supports multiple aspect ratios (16:9, 9:16, 3:4, 4:3) so the output fits any platform — YouTube, TikTok, Instagram, and more.

Why Use It

  1. No editing skills needed
  2. Per-shot storyboard control
  3. Regenerate individual shots
  4. Lip-sync character support
  5. Many visual style choices
  6. Mood text + tag input
  7. Automatic lyrics subtitle matching

Boundaries

  1. Song clip length is at least 10s, max to 90s.
  2. Video content is fully AI-generated — no manual timeline editing now.
  3. In Storyboard mode, users can regenerate individual shot images before final generation; shot timing is system-assigned (by lyrics timeline).
  4. Character lip-sync availability is character-dependent, please ensure that the character image contains a clear face.
  5. Generation costs 40 Gold per second.

  2. Function Entry 2: Song more pop-up window → Download video/Video

Why Use It

Replace

Select any segment for local regeneration, supporting lyric and style modifications while ensuring natural transitions

Core Capabilities

  1. Precise local segment replacement
  2. Support lyric content modification
  3. Support specifying new styles
  4. Automatically maintain natural transitions with surrounding content

Why Use It

  1. No need to start over: Only change the parts you want, keeping what you like
  2. Precise control: Modify down to the measure level
  3. Seamless transitions: AI ensures modified segments naturally flow with surrounding content

Boundaries

Replace is suitable for fine-tuning locally unsatisfactory parts. Recommended replacement segment length is between 4-16 measures. Segments too short (<4 measures) may struggle to fully express style changes; segments too long (>32 measures) should be split into multiple replacements for better control

Music Edit

Edit（Fine-Tune Regions）

Regenerate selected phrases of a song.

Core Capabilities

When your track has minor flaws, there's no need to reroll the whole song — just regenerate the affected phrases to keep most of it and fix only the flawed parts.

Why Use It

Fix minor flaws without rerolling — pinpoint and repair lyrics, vocals, or melody issues; lower generation costs and make perfecting your track smoother.

Boundaries

  1. Regenerate individual lines the AI mis-sang to fix flaws, without changing the lyrics or melody.
  2. Regenerate unsatisfactory lyrics and melody together.
  3. Edit only the unsatisfactory lyrics, keeping the melody unchanged.
  4. Change the melody of unsatisfactory phrases, keeping the lyrics unchanged.

Entry

  1. Go to the Library screen, tap the Remix/Edit button, then tap Edit to open the Edit screen.

How to Use

  1. Go to the Library screen, tap the Remix/Edit button, then tap Edit to open the Edit screen.
  2. Tap the start and end lines of the lyrics you want to change to set the regeneration range.
  3. Edit the selected lyrics.
  4. Turn the Keep melody feature on or off.
  5. Tap ReCreate to generate a full new song — only the selected part is regenerated, while the unselected parts stay unchanged.

Trim｜Audio Trimming

Select a segment — keep what you want, cut the rest.

Core Capabilities

Trim ends: quickly remove silence at the start or a trailing tail at the end.
Preview before applying: confirm your selection before you cut.

Why Use It

The most common and simplest edit — easy to pick up.
Work right on the waveform — what you select is exactly what you get.

Boundaries

It only "cuts" — it won't change the audio content itself.

Entry

  1. Go to the Library page, select the song to trim, tap the "···" button, choose Edit, then tap the Trim button to trim the song.
  2. Tap Music Create and select Trim to upload audio and trim it.

How to Use

  1. Open the trim screen.
  2. Drag the start and end points to select the audio segment you want to keep.
  3. Tap Trim to remove the audio outside the selected range.
  4. Trim as many times as needed until you're happy, then tap Save to save it as a new song.

Mureka Co

An AI music co-worker that lets creators control DAW and call all AI generation capabilities through natural language conversation.

Natural Language DAW Control

Control your DAW through natural language — no menus, no shortcuts to memorize. Mureka Co translates what you say into DAW commands and executes them instantly.

Core Capabilities

  1. Track management: Create MIDI or audio tracks, rename, delete, mute, and unmute
  2. Clip operations: Create clips, move clips to a specific position, delete clips
  3. Session parameters: Set global BPM, change time signature
  4. Track parameters: Adjust volume and pan
  5. Effect chains: Load plugins onto a track and control their signal order (e.g., Reverb → EQ)
  6. Import / Export: Import local audio to a specific track position, export individual stems, bounce the full mix

Why Use It

  1. From idea to action in one sentence: Eliminates both "I have the idea but can't figure out the controls" and "I know the controls but lose my flow doing them" — creativity stays uninterrupted
  2. Non-destructive by design: Every action is previewed before it runs and supports standard DAW undo, so you're always in control of your session
  3. Zero learning curve: Nothing about your existing DAW workflow changes — repetitive tasks just get faster

Boundaries

  1. Currently supports Ableton Live and Reaper; other DAWs are not supported
  2. Available on both macOS and Windows
  3. Natural language control requires an active connection between Mureka Co and your DAW; generation features remain available if the connection is dropped
  4. Fine-grained plugin parameter adjustments (e.g., specific compression ratios or EQ gain values) are not currently supported — use the DAW interface for those

Entry

  1. Natural language conversation

How to Use

  1. User: "Create a new MIDI track called Synth Lead, and set the BPM to 120"
  2. → A new MIDI track named Synth Lead is created and the session BPM is updated to 120
  3. User: "Add reverb and EQ to the Vocal track, put reverb first in the chain"
  4. → Reverb and EQ are loaded onto the Vocal track in the correct signal order

Upload Local Files and Create from Your Own Material

Upload your own audio, images, or video to unlock Remix, Extend, Local Edit, MIDI Export, Voice Clone, Soundtrack, and more — turning AI into a true extension of your existing work.

Core Capabilities

Drop audio (mp3 / wav / flac / m4a), images (jpg / png), or video (mp4 / mov / mkv / avi) directly into the input box
Pair the upload with a natural language prompt to trigger the right creation flow
The agent automatically extracts style, duration, BPM, and other parameters from your file to guide generation
Supported capabilities:

  1. Audio Ref: Analyzes the style of an uploaded track and generates a new song in the same vibe — original audio untouched
  2. Remix (lyrics optional): Re-arranges an uploaded track; keep the original lyrics or swap in new ones — written by the agent or yourself
  3. Extend (forward / backward): Extend from any point in either direction; the generated segment splices in seamlessly
  4. Local Edit: Surgically replace a specific time range — either preserving the original melody or generating something entirely new
  5. MIDI Export: Extracts the main melody from uploaded audio and outputs a MIDI file, ready to drop onto any DAW track
  6. Voice Clone: Captures the vocal timbre from an uploaded track and uses it to sing new material (only available when vocals are detected)
  7. Soundtrack: Upload an image or video; the agent reads the mood and generates a score matched to the duration

Why Use It

  1. Your material is your best prompt: A reference track or video clip says more than any text description — just upload it and go
  2. Fits your existing workflow: Upload from your local files the same way you always have; no cloud migration required

Boundaries

  1. Image uploads are limited to Soundtrack scoring and lyric-video use cases; images cannot be used to trigger other generation types
  2. Supported formats: audio — mp3 / wav / flac / m4a; image — jpg / png; video — mp4 / mov / mkv / avi
  3. Voice Clone is only available when the agent detects vocals in the uploaded audio; purely instrumental files will not trigger it
  4. Remix with lyrics replacement first transcribes the original lyrics and shows them for your confirmation; accuracy depends on the clarity of the original mix
  5. For Local Edit, the recommended replacement length is 4–32 bars; segments shorter than 4 bars may not express style changes fully, and longer segments are best split into multiple passes
  6. MIDI Export works best for melodic instruments; conversion accuracy for complex chords and percussion is limited

Entry

  1. Natural language prompt + drag-and-drop upload

How to Use

  1. Click the attachment icon in the input box or drag a file directly into it, then add a natural language prompt to trigger the corresponding capability.
  2. Example: Upload demo.mp3 "Generate a song in a similar style to this"
